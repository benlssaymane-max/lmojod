# 🚀 Premium E-Commerce Store - Quick Setup

## Prerequisites
- **Node.js 18+** (Required)
- **PostgreSQL** (For database, optional for demo)

## Step 1: Install Node.js
1. Go to https://nodejs.org/
2. Download the **LTS version** (recommended for most users)
3. Run the installer and follow the setup wizard
4. **Restart your computer** after installation

## Step 2: Run the Project
1. Double-click `setup-and-run.bat` in this folder
2. The script will:
   - Check if Node.js is installed
   - Install project dependencies
   - Start the development server on port 7001

## Step 3: Access Your Store
Open your browser and go to: **http://localhost:7001**

## Troubleshooting

### "npm is not recognized"
- Node.js installation was not completed properly
- Try reinstalling Node.js from the official website
- Make sure to restart your computer after installation

### Port 7001 already in use
- Close other applications using port 7001
- Or edit `setup-and-run.bat` to use a different port

### Database connection errors
- For full functionality, you'll need PostgreSQL
- For demo purposes, the store will work without a database
